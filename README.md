# Ilm-e-Jafar Standalone

یہ project موجودہ چشتی حاضرات ایپ کے Ilm-e-Jafar حصے کو الگ Android application structure میں منتقل کرتا ہے۔

## شامل modules
- Ilm-e-Jafar dedicated Home + navigation
- جفر: صغیر، جامع، جدول، کبیر
- علم الابجد + تمام موجودہ tabs/services/data
- علم الاعداد
- اسم اعظم، استخراج اسم، اسماء الحسنی
- غالب و مغلوب
- روحانی تشخیص، روحانی حسابات
- موافقات اعداد، موافقات حروف
- قلب و عکس
- تکسیر بسطی، حروف، متوسطات، صوامت
- بسط و قبض
- فالنامہ
- متعلقہ Jafr engines, rules, repositories اور local data
- Urdu fonts/theme

## اگلا مرحلہ
پہلے standalone project کو build/run کر کے structure verify کریں۔ پھر KazSoft Ilm-e-Jafar کے مقابلے میں ہر calculator کا input → processing → result flow reverse-engineer کر کے verified implementation مکمل کی جائے گی۔
